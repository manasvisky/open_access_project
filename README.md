# Open Access Energy Dashboard

Power BI dashboard developed during my internship at **Top Notch Energy Solutions** to analyse open access electricity data.
The dashboard provides interactive insights into energy consumption, billing, financial performance, and client-wise reporting using dynamic visualisations.

### Tech Stack

- Power BI
- DAX
- Power Query
- Microsoft Excel


### Key Features

- Interactive dashboards with slicers and filters
- Energy consumption analysis
- Billing and cost analysis
- Financial KPI tracking
- Client-wise performance insights
